🚨 Ataques de força bruta são os mais comuns em RouterBoards expostos na internet. Configure imediatamente!

🔐 Anti Brute Force — SSH (22)
Detecta múltiplas tentativas de conexão SSH e bloqueia o IP por 1 hora

add chain=input protocol=tcp dst-port=22 connection-state=new action=add-src-to-address-list address-list=ssh_stage1 address-list-timeout=1m comment="SSH BF Detect"

Comando RouterOS

🚫 Bloquear Pacotes TCP Suspeitos (NULL, XMAS, FIN)
Pacotes com flags anormais são usados para fingerprinting e evasão
DROP
Comando RouterOS
/ip firewall filter
add chain=input protocol=tcp tcp-flags=fin,syn action=drop comment="Drop FIN+SYN"
add chain=input protocol=tcp tcp-flags=fin,rst action=drop comment="Drop FIN+RST"
add chain=input protocol=tcp tcp-flags=fin,!ack action=drop comment="Drop FIN sem ACK"
add chain=input protocol=tcp tcp-flags=syn,rst action=drop comment="Drop SYN+RST"
add chain=input protocol=tcp tcp-flags=!fin,!syn,!rst,!ack,!urg,!psh action=drop comment="Drop NULL packet"
add chain=input protocol=tcp tcp-flags=fin,psh,urg,!syn,!rst,!ack action=drop comment="Drop XMAS packet"

📡 Proteção ICMP / Ping Flood

Controle e limitação de pacotes ICMP para prevenir ataques de ping flood e Smurf

📡 Limitar ICMP (Ping) de entrada
Aceita apenas 10 pings por segundo, descarta o restante
DROPINPUT
Comando RouterOS
/ip firewall filter
add chain=input protocol=icmp icmp-options=8:0 limit=10,5:packet action=accept comment="ICMP Echo Request - Rate Limited"
add chain=input protocol=icmp icmp-options=8:0 action=drop comment="ICMP Flood - Drop excesso"
add chain=input protocol=icmp icmp-options=0:0 action=accept comment="ICMP Echo Reply - Accept"
add chain=input protocol=icmp icmp-options=3:0-15 action=accept comment="ICMP Unreachable - Accept"
add chain=input protocol=icmp icmp-options=11:0-255 action=accept comment="ICMP Time Exceeded - Accept"
add chain=input protocol=icmp action=drop comment="Drop outros ICMP"

Detecta e bloqueia pacotes com endereços de origem forjados

🎭 Anti IP Spoofing
Verifica se o IP de origem bate com a interface de entrada
DROP
Comando RouterOS

add chain=input in-interface=ether1 src-address=192.168.0.0/16 action=drop comment="Drop Spoof RFC1918 na WAN"

💣 Anti LAND Attack
LAND Attack: pacote onde src-ip == dst-ip — trava o IP stack do alvo
DROP
Comando RouterOS
/ip firewall filter
add chain=input src-address=0.0.0.0 action=drop comment="Drop Source 0.0.0.0"
add chain=input protocol=tcp src-address=dst-address action=drop comment="Drop LAND Attack (src==dst)"

Bloqueia pacotes que usam o próprio IP do roteador como origem (anti-spoof local)
DROPINPUT
Comando RouterOS
/ip firewall filter
add chain=input in-interface=ether1 src-address=[/ip address get [find interface=ether1] address] action=drop comment="Drop pacotes com IP do router como src na WAN"

🧠 Regras Layer 7 (Camada de Aplicação)

Inspeção profunda de pacotes para detectar e bloquear padrões maliciosos no payload

⚠️ Regras L7 consomem mais CPU. Use com moderação em roteadores com hardware limitado.
🧠 Criar Padrões L7 (Layer7 Protocol)
Define expressões regulares para detectar tráfego malicioso no conteúdo
DROP
Comando RouterOS
/ip firewall layer7-protocol
add name=block_torrent regexp="^(\x13bittorrent|azureus|bittorrent)"
add name=block_skype regexp="^(\x04\x7f|\x30\x52|\x30\x60)"
add name=block_winbox_probe regexp=".*winbox.*"
add name=detect_nmap regexp="nmap|masscan|zmap"
add name=block_cmd_injection regexp="(\.\./|;ls|;cat|wget |curl |chmod |bash |/bin/sh)"
add name=block_sql_inject regexp="(union select|drop table|insert into|' or '1'='1)"

/ip firewall filter
add chain=forward layer7-protocol=block_torrent action=drop comment="L7 Block Torrent"
add chain=forward layer7-protocol=detect_nmap action=add-src-to-address-list address-list=port_scanners address-list-timeout=1d comment="L7 Detect Nmap"
add chain=forward layer7-protocol=block_sql_inject action=drop comment="L7 Block SQL Inject"
add chain=forward layer7-protocol=block_cmd_injection action=drop comment="L7 Block CMD Inject"

🚀 FastTrack — Aceleração de Tráfego

Bypass do firewall para conexões já estabelecidas, aumentando throughput e reduzindo CPU

✅ FastTrack pode aumentar a velocidade do roteador em até 10x para tráfego de passagem. Requer RouterOS 6.29+
🚀 FastTrack para Conexões Estabelecidas
Conexões já verificadas pelo firewall ganham caminho rápido (hardware offload)
FASTTRACKFORWARD
Comando RouterOS
/ip firewall filter
add chain=forward connection-state=established,related action=fasttrack-connection comment="FastTrack Established/Related" hw-offload=yes
add chain=forward connection-state=established,related action=accept comment="Accept Established/Related (after FastTrack)"
🚀 FastTrack Seletivo por Interface
Aplica FastTrack apenas para tráfego WAN→LAN e LAN→WAN
FASTTRACK
Comando RouterOS
/ip firewall filter
add chain=forward in-interface=ether1 out-interface=bridge connection-state=established,related action=fasttrack-connection comment="FastTrack WAN->LAN" hw-offload=yes
add chain=forward in-interface=bridge out-interface=ether1 connection-state=established,related action=fasttrack-connection comment="FastTrack LAN->WAN" hw-offload=yes
📋 Verificar Status do FastTrack
Comando para verificar se o FastTrack está funcionando corretamente
VERIFICAR
Verificação
/ip firewall connection print where fasttracked=yes
/ip firewall filter print stats where comment~"FastTrack"

add chain=input connection-state=invalid action=drop comment="[INPUT] Drop Invalid State"

# --- ICMP Limitado ---
add chain=input protocol=icmp icmp-options=8:0 limit=10,5:packet action=accept comment="[INPUT] ICMP Echo - Rate Limited"
add chain=input protocol=icmp icmp-options=8:0 action=drop comment="[INPUT] ICMP Flood Drop"
add chain=input protocol=icmp icmp-options=0:0 action=accept comment="[INPUT] ICMP Echo Reply"
add chain=input protocol=icmp icmp-options=3:0-15 action=accept comment="[INPUT] ICMP Unreachable"
add chain=input protocol=icmp icmp-options=11:0-255 action=accept comment="[INPUT] ICMP Time Exceeded"
add chain=input protocol=icmp action=drop comment="[INPUT] Drop outros ICMP"

# --- Bogon IPs ---
add chain=input src-address-list=bogon_list in-interface=ether1 action=drop comment="[INPUT] Drop Bogon IPs"

# --- TCP Flags Inválidos ---
add chain=input protocol=tcp tcp-flags=fin,syn action=drop comment="[INPUT] Drop FIN+SYN"
add chain=input protocol=tcp tcp-flags=fin,rst action=drop comment="[INPUT] Drop FIN+RST"
add chain=input protocol=tcp tcp-flags=fin,!ack action=drop comment="[INPUT] Drop FIN sem ACK"
add chain=input protocol=tcp tcp-flags=syn,rst action=drop comment="[INPUT] Drop SYN+RST"
add chain=input protocol=tcp tcp-flags=!fin,!syn,!rst,!ack,!urg,!psh action=drop comment="[INPUT] Drop NULL Packet"
add chain=input protocol=tcp tcp-flags=fin,psh,urg,!syn,!rst,!ack action=drop comment="[INPUT] Drop XMAS Packet"

# --- Anti Spoofing ---
add chain=input in-interface=ether1 src-address=192.168.0.0/16 action=drop comment="[INPUT] Drop RFC1918 Spoof WAN"
add chain=input in-interface=ether1 src-address=10.0.0.0/8 action=drop comment="[INPUT] Drop 10.x Spoof WAN"
add chain=input in-interface=ether1 src-address=172.16.0.0/12 action=drop comment="[INPUT] Drop 172.x Spoof WAN"
add chain=input in-interface=ether1 src-address=127.0.0.0/8 action=drop comment="[INPUT] Drop Loopback Spoof"
add chain=input src-address=0.0.0.0 action=drop comment="[INPUT] Drop Src 0.0.0.0"

# --- SYN Flood ---
add chain=input protocol=tcp tcp-flags=syn connection-state=new action=jump jump-target=syn-flood comment="[INPUT] SYN Flood Check"
add chain=syn-flood limit=400,5:packet action=accept comment="[SYN] Accept Rate"
add chain=syn-flood action=add-src-to-address-list address-list=syn_flooders address-list-timeout=10m comment="[SYN] Blacklist"
